App Store Connect

Reconnect ChatGPT using an authorized connection.

Reconnect in three steps

  1. Generate a reconnection code for an authorized connection below.
  2. In ChatGPT plugin settings, select AppStoreConnect and choose Reconnect for the account you use.
  3. Enter the code on the “Connect your application” page to finish.

Each code can be used once and expires after ten minutes. Generating another code replaces the previous one.
